# Inventario de Tienda

Proyecto escolar simple de CRUD de inventario.

- `backend/`: API REST en Ktor + Kotlin + Exposed + SQLite (puerto 8080)
- `frontend/`: Interfaz en Next.js + React + TypeScript (puerto 3000)

Sigue la guía paso a paso que Claude te dio en el chat para configurar,
ejecutar y probar cada parte. Este ZIP ya trae el código completo de
ambos proyectos, listo para abrir e instalar dependencias.
